# Room 09 Drum Machine

A responsive nine-pad drum machine built with React and Vite. Trigger pads by clicking or using `Q W E / A S D / Z X C`. The master slider controls output volume, and the power switch suspends or resumes the audio engine.

Drum voices are synthesized with the Web Audio API, so the instrument runs without external sample files.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
